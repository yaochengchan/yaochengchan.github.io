# yaochengchan.github.io

Personal portfolio site for Yao-Cheng Chan, served free by GitHub Pages.

This is plain HTML and CSS, so there's no build step. (`.nojekyll` tells GitHub not to run Jekyll.)

## Where things are
| What | File |
|---|---|
| Homepage | `index.html` |
| Case studies | `work/<name>/index.html` |
| Experience | `experience/index.html` |
| Publications | `publications/index.html` |
| All styling (colors, fonts, layout) | `assets/site.css` (colors are at the top under `:root`) |
| Images and videos | `assets/img/` |
| Résumé PDF | `files/CV.pdf` (replace this file to update the résumé everywhere) |

Old URLs (`/HRE/`, `/puppet/`, `/vid2real/`, `/personality/`, `/cv/`) redirect to the new pages.

## Making a quick edit
Open the page's `index.html` on GitHub, click the pencil icon, change the text, and commit. The site updates in about a minute.
